# KhaiKang

KhaiKang is an open-source, self-hostable workflow platform for engineering teams.

## Name Origin

KhaiKang comes from the Taiwanese Hokkien phrase "Khai-kang" (`開工`), which means "start working" or "begin work."
The name reflects the project's purpose: helping teams start, organize, and move work forward in a practical way.

It focuses on the core workflow that smaller and mid-sized teams actually need:

- Issue tracking
- Agile planning
- Test case management
- CI integration
- Human-reviewed AI-assisted configuration changes

KhaiKang is not intended to be a full Jira clone. The goal is to keep the system focused, maintainable, and practical for real software delivery.

## Why KhaiKang exists

Existing tools are often either too expensive, too heavy, or too fragmented for teams that want:

- full control of their data
- a simpler workflow model
- test management tied directly to delivery
- CI feedback linked back to work items
- AI assistance without unsafe automatic changes

## Roadmap

- v0.1: core project management
- v0.2: test case management
- v0.3: CI and Jenkins integration
- v0.4: AI-assisted proposals with human approval

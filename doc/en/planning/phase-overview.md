# Phase Overview

Status: synchronized on 2026-08-10. Traditional Chinese counterpart: [階段規劃總覽](../../zh-TW/04-planning/01-phase-overview.md).

The current phase is RC release hardening. Identity, Project/Issue, manual Test Management, Workspace–Project links, attachments, the baseline migrations, shared versioning, and RC image publication are implemented. `v0.1.0-rc.2` has passed backend/frontend checks and published immutable API/Web images.

Current priorities are release preparation/publication automation, pull-request verification, a fresh-image core-flow smoke test, Docker-volume persistence, and an isolated PostgreSQL plus attachment backup/restore drill. Full desktop/mobile acceptance, Playwright, automation import, AI execution, and custom roles/workflows/fields remain later phases.

See [Release automation and delivery drill](./release-automation.md) for the active work, [MVP release closure](./mvp-release-closure-plan.md) for the accepted MVP boundary, and [Backlog](./backlog.md) for deferred work.

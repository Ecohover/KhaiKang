# KhaiKang v0.1.0-rc.2

This release candidate keeps the MVP scope of `v0.1.0-rc.1` and fixes the
integration-test host configuration used by the release pipeline.

## Fixed

- Isolated each integration-test host's database connection configuration.
- Removed the process-wide connection-string environment variable that could be
  cleared by another parallel test fixture.
- Routed the system endpoint tests through the shared SQLite integration-test
  factory.

## Included

- Project, member, issue, assignment, status, list, and board workflows.
- Manual test workspaces, suites, cases, plans, runs, and result recording.
- Stable Test Run snapshots that preserve case and step content at execution time.
- Issue, Test Case, and Test Run Item attachments using UUID storage keys while
  retaining original file names.
- Markdown-based rich content, images, file download dialogs, and read-only rendering.
- PostgreSQL baseline migrations and Docker Compose persistent volumes.
- Shared product versioning across the API, web UI, OCI labels, Git tags, and
  Docker image tags.

## Images

```text
ecohover/khaikang-api:0.1.0-rc.2
ecohover/khaikang-web:0.1.0-rc.2
```

Use [`deploy/compose/docker-compose.yml`](../../deploy/compose/docker-compose.yml)
with `KHAIKANG_IMAGE_TAG=0.1.0-rc.2` rather than running either image alone.

## RC limitations

- Desktop and mobile manual acceptance remains in progress.
- Backup and restore procedures still require a formal release drill.
- The consolidated Initial migrations expect a new PostgreSQL database; databases
  using the earlier development migration history require a separate migration plan.
- Automated test execution and historical security-maintenance branches are not
  part of this release candidate.

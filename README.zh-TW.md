# KhaiKang

KhaiKang 是一套開源、可自架的工程團隊工作流平台。

## 名稱緣起

`KhaiKang` 來自台語羅馬字 `Khai-kang`，對應漢字「開工」，意思就是「開始工作」。
這個名稱也對應專案的核心精神：讓團隊可以開始、整理並持續推進工作。

它專注在工程團隊真正常用的核心流程：

- Issue 管理
- 敏捷規劃
- 測試案例管理
- CI 整合
- 具人類審核機制的 AI 輔助設定變更

KhaiKang 不是要完整複製 Jira，而是要做一套更聚焦、可維護、適合實際軟體交付流程的系統。

## 為什麼要做 KhaiKang

目前市面上的工具常見問題是：

- 太貴
- 太重
- 功能太分散
- 測試管理與交付流程沒有真正串起來
- AI 功能有，但缺少安全的人工審核流程

KhaiKang 的目標是把這些流程整合起來，讓團隊可以自己掌控資料與工作方式。

## 初期範圍

- 專案管理
- Issue / Board / Workflow
- 測試案例管理
- Jenkins / CI 回寫

## 後續願景

- AI 協助整理 bug 與測試資訊
- AI 協助簡化複雜設定
- AI 根據需求單產出測試與開發規劃
- 所有高風險設定變更都保留人類審核
